# Real phone photos of sketches ("من صورة")

Put your photos here (any name, `.jpg`, `.jpeg` or `.png`), straight from the phone.
`flutter test test/sketch_detect_test.dart` then checks each one: a closed shape must be
found, with 3 to 12 corners, and it prints what it found (corners, sheet straightened, tilt).
These photos are only for the tests: they are never part of the app.
