Plan de Verger 🍎

Dessinerjardin.fr est une application en ligne très simple d’utilisation pour élaborer le plan de votre verger. Dessinerjardin.fr vous permet de consigner et de garder en mémoire toutes les informations relatives à votre verger (les noms, les variétés …).

Pour réaliser le plan de votre verger, il vous suffit d’importer un cadastre,  une image ou bien encore de dessiner les contours de votre parcelle. 

En vous aidant des outils de mesure, distance, surface, disposez sur votre plan les arbres fruitiers que vous souhaitez planter et matérialisez l’emplacement de ceux existants. Pour ce faire, choisissez dans notre catalogue le fruitier correspondant, puis glissez-déposez le sur le plan. Vous pouvez également ajouter des légendes et autres éléments tels que le plan d’irrigation.

Notre application dispose d'une large base de données d'espèces végétales avec des informations consultables depuis les fiches des plantes.  

Avec Dessinerjardin.fr, vous pouvez éditer et enregistrer plusieurs versions de votre plan afin de les partager ou tout simplement de suivre l’évolution de votre verger dans le temps.
